# Data and knowledge store

The AVerImaTeC benchmark data, claim images, and organizer-provided knowledge
store are **not redistributed** here.

Obtain the official resources from the AVerImaTeC/FEVER shared-task pages and
place them locally. The archived paper scripts expect claim-specific knowledge
store files and claim images. See `docs/PATHS_AND_INPUTS.md` for the path
mapping used in the original workspace.

Do not commit benchmark data, image archives, model caches, or credentials to
this repository unless their licenses explicitly allow redistribution.
